# Testing conventions

`make test` runs everything.

## Fixtures
- `client` — a `TestClient` on a **throwaway database and upload directory**.
- `samples` — the path to `data/samples/`. Use the files there; do not build geometry inline unless the
  case is not covered. `tests/conftest.py::upload(client, path, as_name=...)` posts one.
- `data/samples/` is generated by `scripts/make_samples.py`. Add a case there, not by hand.

## What is in data/samples/
| file | what it is for |
|---|---|
| `cube.stl`, `cube-ascii.stl`, `torus.stl` | STL happy paths (12 / 12 / 2304 triangles) |
| `empty.stl`, `not-a-mesh.stl` | STL unhappy paths |
| `cube.obj` | quad faces — must be triangulated (12 triangles after) |
| `cube-tris.obj` | already triangles, `v//vn` index form |
| `cube-negative.obj` | relative (negative) indices — legal |
| `cube-with-material.obj` | `mtllib`, `usemtl`, `o`, `s` lines — to be ignored |
| `points-only.obj` | vertices, no faces |
| `broken.obj` | a bad vertex on line 5 |
| `index-out-of-range.obj` | a face referencing vertex 9 of 3 |

## Naming
One test per acceptance criterion, named by number: `test_ac4_bad_line_is_422_with_line_number`.
A red test then points at a sentence in the spec, not just at a function.

**The spec's author writes the tests, from the criteria, before the handoff** — not the session that
implements. Otherwise they pass against that session's own reading and measure nothing.
